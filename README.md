# Bewerbungsseite

Eine statische Seite: kein Framework, kein Build-Schritt, keine Schriften oder
Zählpixel von fremden Servern. Wer sie ändern will, braucht einen Texteditor.

**Live: https://litmeyer.github.io**

## Was wo liegt

| Datei | Zweck |
| --- | --- |
| `index.html` | die ganze Seite, ein Dokument |
| `stil.css` | die Gestaltung |
| `stil-b.css` … `stil-f.css` | Entwürfe zum Vergleichen; der Umschalter unten rechts auf der Seite wechselt zwischen ihnen |
| `diagramm-*.svg`, `heatmap-*.svg` | die Grafiken, aus den Rechenergebnissen erzeugt |
| `myth-optimizer.html` | das verlinkte Werkzeug – eine eigenständige Datei, läuft ohne Server und ohne Installation |

## Hinweise

Die Seite trägt `noindex, nofollow` und soll nicht in Suchmaschinen erscheinen.
Sie ist als Link in Bewerbungen gedacht, nicht als öffentliches Angebot.

Die Entwürfe B bis F und der Umschalter sind vorläufig. Sobald die Gestaltung
feststeht, bleibt eine einzige `stil.css` übrig.
